# 빌라드지디 안산점 WORKON 직원 관리 확장

## 현재 상태
기존 `index.html`, `pc.html`, `mobile.html`과 지도 이미지는 보존됩니다. `staff.html`은 직원용, `admin.html`은 관리자용 화면입니다. 아직 Supabase 연결 전에는 계정 가입/로그인/이력 저장이 활성화되지 않습니다. 연결 설정을 완료한 후 배포해야 실제 데이터가 저장됩니다.

## 1. Supabase 프로젝트 생성
1. https://supabase.com/dashboard 에서 새 프로젝트를 만듭니다.
2. **SQL Editor**를 열고 동봉된 `database.sql` 전체를 실행합니다.
3. Authentication > Providers > Email에서 이메일 인증을 켭니다. 비밀번호 최소 12자, 가입 메일 발송 설정도 확인합니다.
4. Authentication > URL Configuration에서 Site URL을 `https://villadegd-ansan-parking.vercel.app` 로 지정합니다. Redirect URL에도 해당 주소를 추가합니다.
5. Project Settings > API 또는 Connect에서 **Project URL** 및 **Publishable/anon key**를 확인합니다. `service_role`/secret 키는 사용하지 않습니다.
6. `config.js` 파일의 `REPLACE_WITH_SUPABASE_URL`과 `REPLACE_WITH_SUPABASE_PUBLISHABLE_KEY`를 각각 교체합니다. 이 두 값은 공개 브라우저용이며 접근 제어는 `database.sql` RLS가 담당합니다.

## 2. Vercel에 재배포
이 폴더를 원래 Vercel 프로젝트 `villadegd-ansan-parking`에 배포합니다.

터미널 예시 (Node.js 설치 환경):
```
npx vercel login
npx vercel link --project villadegd-ansan-parking --scope newwin4-3215
npx vercel deploy --prod
```
`vercel link`에서 다른 프로젝트를 만들지 말고 기존 프로젝트에 연결하세요. 새 앱으로 배포할 경우 기존 문자 공유 주소가 바뀔 수 있습니다.

## 3. 최초 관리자 등록
1. `https://villadegd-ansan-parking.vercel.app/staff.html` 로 접속합니다.
2. 관리자가 될 본인 계정으로 회원가입하고 이메일 확인을 완료합니다.
3. Supabase SQL Editor에서 `database.sql` 마지막 줄의 예시 SQL을 실제 관리자 이메일로 바꿔 실행합니다.
4. 재로그인한 뒤 `/admin.html`에서 가입 직원 승인을 처리합니다.

## 4. 직원 이용
- 기존 문자 공유 주소 `/`는 그대로 매뉴얼을 보여줍니다. PC와 모바일 매뉴얼 하단에 **직원 로그인 · 교육 / 체크리스트** 버튼이 추가됩니다.
- 직원이 가입 신청 → 메일 인증 → 관리자 승인 → 교육 이수 및 근무일별 체크리스트 제출.
- 관리자 `admin.html`에서는 교육 버전별 이수, 가입 승인, 점검 제출, CSV 내보내기를 확인합니다.

## 보안 및 운영
- RLS에 의해 직원별 조회 범위가 제한됩니다. 제출된 이력은 수정/삭제할 수 없습니다.
- 최초 관리자 권한은 Supabase SQL Editor에서만 부여합니다.
- 관리자 화면에 표시되는 CSV는 직원 개인정보를 포함하므로 안전하게 보관합니다.
- 휴대전화는 개인 식별 보조정보이며 인증 수단은 이메일/비밀번호입니다.
- 로그인 화면의 HTML을 숨기거나 단순 비밀번호를 넣는 방식만으로는 데이터가 보호되지 않습니다.
- 업무 체크리스트와 자체 교육 이수는 법정 안전보건교육의 적법한 실시·이수 요건을 자동으로 충족하지 않습니다.
- 교육자료 변경 시 `config.js`의 `courseVersion`을 올려 재교육을 구분하세요.
- 서비스 운영 전 권한/미승인/다른 사용자 데이터 차단, 이메일 확인, 휴대전화 화면과 재배포를 반드시 테스트하세요.
